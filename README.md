# Sistema de Biblioteca Digital

Projeto desenvolvido em Python para gerenciamento de documentos digitais de uma biblioteca universitária.

## Objetivo

Automatizar o gerenciamento de arquivos digitais, permitindo operações de listagem, adição, renomeação e remoção de documentos.

## Funcionalidades

* Listar documentos
* Adicionar documentos
* Renomear documentos
* Remover documentos
* Organização por tipo de arquivo
* Organização por ano de publicação

## Estrutura do Projeto

documentos/
├── pdf/
├── epub/
└── docx/

## Tecnologias Utilizadas

* Python
* Google Colab
* Git
* GitHub
